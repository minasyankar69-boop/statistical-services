# Портал статистических услуг — запускаемый веб-проект

## Что уже реализовано
- Главная страница и выбор типа заявителя.
- Раздельные формы физического и юридического лица.
- Сохранение заявок в SQL-базе данных.
- Номер заявки и публичная проверка статуса по номеру + email.
- Административная панель с изменением статусов.
- CSRF-защита форм и ограничение размера запроса.

## Локальный запуск
1. Установите Python 3.11 или новее.
2. Выполните `pip install -r requirements.txt`.
3. Задайте переменные окружения:
   - `SECRET_KEY` — длинная случайная строка.
   - `ADMIN_PASSWORD` — уникальный пароль администратора.
   - `COOKIE_SECURE=false` только для локального тестирования по HTTP.
4. Запустите `python app.py`.
5. Откройте `http://127.0.0.1:5000`.

## Публикация через Render
1. Создайте GitHub-репозиторий и загрузите в него `app.py`, `requirements.txt`, `render.yaml`.
2. В Render выберите New → Blueprint и подключите репозиторий.
3. Render создаст веб-сервис и PostgreSQL по `render.yaml`.
4. При настройке задайте `ADMIN_PASSWORD` как секретное значение.
5. После успешного деплоя откройте выданный Render URL.
6. Административная панель: `/admin`.

## Важно перед реальным запуском
Это рабочая стартовая версия, но не готовая государственная система и не юридическое заключение.
Перед приёмом реальных персональных данных необходимо:
- согласовать правовое основание, текст согласия и политику конфиденциальности;
- проверить применимые требования к хранению и локализации персональных данных;
- включить резервное копирование, мониторинг, ограничение попыток входа и аудит действий сотрудников;
- использовать корпоративную почту/уведомления и защищённое файловое хранилище, если нужны вложения;
- проверить безопасность независимым специалистом;
- заменить демонстрационный каталог услуг на утверждённый перечень и настроить реальные сроки/регламенты.

В текущей версии загрузка файлов намеренно не реализована: принимать документы без антивирусной проверки и защищённого хранилища небезопасно.
